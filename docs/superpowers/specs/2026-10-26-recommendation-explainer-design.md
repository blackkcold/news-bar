# 本地推荐解释中心：实施规格

用户已在会话中确认方案并要求多个 subagent 边核查边执行；随后明确要求携带全部未提交改动进入新工作树。本文固化该授权，不增加云画像、付费 API、发版或提交。

## 目标与范围

- 设置 → 通用 → 本地兴趣与隐私增加「推荐原理与我的兴趣」，不新增第九个页签。
- 原生 SwiftUI 详情包含概览、兴趣关联、推荐链路、数据与隐私；可滚动，640×560 设置窗口可用，宽窗口渐进展开。
- 使用本机实际画像与当前推荐快照，不伪造阅读记录。未开启、无证据、暂停、隐私阅读、存储异常分别呈现；查看解释本身不写学习事件、不请求网络、不重排。
- 标题词典包含主题、实体与手动关注维度。关系图仅表示证据/标签命中，不表示因果或语义距离；附文字等价列表。当前语义向量未参与排序，保持关闭，不添加 3D 粒子或力导向依赖。
- 复用现有现代/复古主题、EditorialSurfaceShape、按钮和减动效规范；中文/英文均可用。
- 仓库说明与 App 离线说明共用正文来源，发布包验证资源可读。隐私披露区分行为/画像本地存储与 AI/翻译/调研发送标题及必要上下文。

## 正确性修复

- 曝光绑定信息流自身窗口、列表显示和阅读器遮挡；非活跃/不可见间隔重置连续计时。稳定批次/会话归因，视图重建不制造重复曝光。
- 事件流水与同篇同日最强画像证据分离；保留合法漏斗事件，不因升级删除旧事件。失败打开不构成正向学习。
- 事件归因使用可选 Codable 字段兼容旧库，区分 surface、batch、position、feed/reader 会话和策略/画像版本；不得增加持续设备标识或遥测上传。
- 显式收藏/屏蔽与自动学习解耦；按内容、事件、来源、主题的真实作用域去重。减少主题须幂等，不静默截断长期规则/收藏。
- 关闭停止学习与个性化使用，但不暗示删除；重新开启恢复保留画像必须说明。暂停保留画像。清空个人数据后默认停止学习，保留收藏不重新授权画像；区分个人数据与公开内容缓存。
- 损坏/未知 schema 的存储仍可经显式清空恢复；清空失败不能显示成功。仅操作本应用兴趣库，不自动清除其他浏览器、Cookie、系统备份或真实测试环境数据。
- 关注规范标签及同义词迁移；保留任意关键词的字面匹配。重排轨迹如实记录动态归一化、公共基线、来源/主题惩罚和系统位。明确来源占比为软约束。
- 不凭空重设全套权重或启用语义模型；探索槽可先诚实命名为来源补位。增加固定样本回放与跨来源/缺失特征测试，任何排序变化必须对应测试证据。

- 完整 swift build / swift test；关键曝光、反馈、清空、兼容解码、排名轨迹、离线资源测试。

- 本地 release 构建与资源布局验证；不执行有删除/覆盖/发布副作用的正式 release 脚本。
- 所有原有 13 项改动保留；不提交、不 push、不改版本、不修改 OpenCode 权限配置。
